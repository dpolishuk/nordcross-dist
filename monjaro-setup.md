# NordcrossConfig на Geely Monjaro — инструкция владельца

Приложение показывает HUD на проекции и подаёт в навигатор позицию с вашего
iPhone. Устанавливается один раз, дальше работает само.

Что понадобится: iPhone с приложением-донором (приглашение в TestFlight
пришлёт Дмитрий) и головное устройство машины.

## 1. Установить приложение на ГУ

1. Откройте на ГУ браузер и зайдите на
   **github.com/dpolishuk/nordcross-dist/releases/latest**
2. Скачайте файл `nordcross-config-1.21.apk` (или какой там самый свежий).
3. Откройте скачанный файл → согласитесь на установку. Если система спросит —
   разрешите установку из неизвестных источников.

Если браузера на ГУ нет: скачайте APK на флешку с любого компьютера и
откройте на ГУ через файловый менеджер.

## 2. Разрешить фиктивное местоположение (один раз)

1. Настройки ГУ → О системе/О телефоне → несколько раз нажмите «Номер
   сборки» — появится меню «Для разработчиков».
2. Для разработчиков → «Приложение для фиктивных местоположения» (или
   «Выбрать приложение фиктивного местоположения») → **NordcrossConfig**.

Если такого пункта в меню нет — пропустите этот шаг и напишите Дмитрию,
какая у вас прошивка (приложение само сообщит нам остальное).

## 3. Настроить приложение на ГУ

1. Откройте NordcrossConfig, выдайте все запрашиваемые разрешения
   (поверх других приложений, доступность — для автозапуска).
2. Экран «GPS»: источник — **Bluetooth**. На экране появится код
   сопряжения (6 символов).

## 4. Подключить iPhone

1. Установите приложение-донора из TestFlight (по приглашению) и откройте его.
2. Режим — **BLE/Bluetooth**.
3. Введите код сопряжения с экрана GPS головного устройства.

После этого на экране «GPS» появятся координаты с телефона, а навигатор
начнёт видеть позицию.

## 5. Включить HUD

1. В приложении: экран настроек HUD → включить.
2. HUD должен появиться на проекции (на ветровом стекле).
3. Если проекция включена, а HUD не появился: в настройках HUD выберите
   дисплей вручную из списка.

## Если что-то не работает

Приложение → «Диагностика» → «Экспортировать лог» → отправьте файл Дмитрию.
Большинство проблем мы и так увидим удалённо по телеметрии — если у ГУ есть
интернет.

Нюансы: позиция идёт с iPhone, поэтому телефон должен быть в машине с
открытым приложением; точность — как у GPS телефона.
