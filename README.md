# nordcross-dist

Дистрибутив приложения **NordcrossConfig** (ГУ EX11): APK-релизы для
встроенного обновления (карточка «Обновление приложения», экран «Система»).

Здесь лежат только собранные APK и changelog; исходный код — в приватном
репозитории.

## Как обновляться

1. Включи точку доступа на телефоне (у ГУ нет своего интернета).
2. Подключи ГУ к точке (Настройки → Wi-Fi).
3. NordcrossConfig → Система → «Обновление приложения» → «Проверить» →
   «Обновить» → «Установить».

Первый раз Android спросит разрешение на установку из NordcrossConfig —
разреши (один раз).

## Релизы

Тег релиза = версия приложения (`v1.1` → версия `1.1`). APK прикреплён
как asset `nordcross-config-<версия>.apk`.
